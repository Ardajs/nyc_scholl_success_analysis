# Data

`score.csv` is not used; the project expects **`scores.csv`** in this directory.

The included dataset contains 435 New York City schools and 22 columns, including school identity, borough, enrollment, demographic percentages, SAT component scores, SAT participation, and geographic coordinates.

## Important licensing note

The dataset was supplied for this analysis. Before publishing the repository publicly, verify the dataset's original source and redistribution license. The MIT license in the repository applies to the **code and documentation**, not automatically to the data.
